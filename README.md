# LIQ Launchpad

Monorepo for the LIQ launchpad on Solana.

- `frontend/` — Next.js app (LIQ launchpad UI, "Hit a LIQ" / leanpad.vercel.app)
- `program/` — Anchor program scaffold implementing LIQ V1 mechanics

This repo is extracted from the main OpenClaw workspace for deployment to GitHub as `NoizceEra/liq-launchpad`.
